【项目简介】 旨在深入剖析和实践操作系统底层机理，从零开发基于 RISC-V 64 架构、支持多编程（Multi-programming）的类 Unix 系统。

架构与内存管理：独立实现系统引导（Boot）、中断异常陷入机制以及基于多级页表的虚拟内存管理与物理内存分配（kalloc）。

用户态生态建设：开发了定制化的用户态 Shell 与基础应用（ls/cat/echo），提供精简版的标准 C 库系统调用接口（printf/scanf）。
